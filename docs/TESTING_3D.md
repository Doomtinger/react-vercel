## 🔍 故障排查

### 如果3D场景不显示

**检查1: 依赖是否安装**
```bash
export PATH="$HOME/.nvm/versions/node/v24.14.0/bin:$PATH"
pnpm list | grep -E "three|fiber|drei"
```

应该看到：
- `@react-three/fiber 9.x.x`
- `@react-three/drei 10.x.x`  
- `three 0.185.0`

**检查2: 控制台错误**
- 打开浏览器开发者工具 (F12)
- 查看Console标签页
- 查找错误信息

**检查3: 是否有TypeScript错误**
```bash
# 查看构建输出
pnpm run dev
# 查看是否有编译错误
```

### 如果有ambientLight错误

这个错误通常是因为：
1. 组件使用了错误的导入
2. Three.js类型定义问题
3. React Three Fiber版本不兼容

**解决方案**:
- 使用简化版组件（已提供）
- 确保使用primitive形式的灯光: `<ambientLight />`
- 避免使用自定义封装的灯光组件
